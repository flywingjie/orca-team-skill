# 工作区状态行模板

> 状态行是跨 agent 的唯一实时通道；关键节点必须更新。

## 格式

```text
<单号> 开工：<一句话当前动作>
<单号> 里程碑：<完成到哪一步>，补丁 patches/<单号>/change-01.patch
<单号> 完成：<一句话结果>，补丁包 patches/<单号>/
<单号> 阻塞：<阻塞点>，需要 <谁> 决定 <什么>
<单号> 待阅：<需要人看什么>
<单号> 失败：<失败原因>，证据 evidence/<文件>
```

## 示例

```text
API-014 开工：补分页参数与负路径用例
API-014 里程碑：接口与测试已改，跑门禁中
API-014 完成：分页实现 + 4 条用例全绿，补丁包 patches/API-014/
WEB-021 阻塞：响应类型未生成，需要 INT-001 先生成契约产物
INT-001 待阅：两支补丁已合入，全量门禁 2 条失败，详见 evidence/
```

## 要求

- 以单号开头，便于检索。
- 一句话说清；不贴长日志。
- 阻塞必须写“需要谁决定什么”。
- 完成后写补丁包路径。
- 失败必须显式写“失败”，不得写“基本完成”。
