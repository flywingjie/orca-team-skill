# 工单 VER-001：基于集成分支实跑用例与门禁

## 目标

基于集成分支 `feature/example-integration` 跑验收用例与门禁命令，产出用例结果、缺陷清单与证据。
本单**不改功能代码**，只跑、只记、只报。

**不碰**：
- 全部功能代码（`server/**`、`web/**`）
- `contracts/**`

## 改动

1. 在集成分支上执行验收用例，输出每条用例的通过/失败与耗时。
2. 执行门禁命令（lint / typecheck / test / build），逐条记录退出码。
3. 产出缺陷清单（含复现步骤与证据路径）；无缺陷也要显式写「无缺陷」。
4. 证据落盘到补丁包 `evidence/`。

## 约束

- 口径：`ots:V-4`（自测结果必须能在 `evidence/` 找到对应输出）。
- 禁改：全部功能代码与契约文件；本单只允许新增 `tests/acceptance/` 下的用例。
- 契约：本单不涉及契约定义与产物。
- 迁移号：无。
- 基线：`feature/example-integration`。
- 越界处置：需要改范围外文件 / 改契约 / commit / push / 合并时，停下上报。
- 歧义处置：业务歧义停下上报；实现歧义自行决定并在回报中写明选择与理由。

## 归属

- 本单独占文件：
  - `tests/acceptance/`
- 依赖：INT-001
- 与他单相邻：上游 `INT-001`；下游 `ACC-001` 消费本单结果。
- 分支：`feature/VER-001-verify`
- 补丁包路径：`patches/VER-001/verifier/`
