# 工单 ACC-001：条款级验收核验

## 目标

对 `SPEC-001` 的规格与 `VER-001` 的实跑结果做条款级核验，产出验收结论、缺口与遗留风险清单。
本单**不豁免偏差、不代写实现**。

**不碰**：
- 全部功能代码与契约文件
- `tests/acceptance/`（归 `VER-001` 单）

## 改动

1. 逐条核对规格的验收标准，产出核验表（条款 → 判定 → 证据路径）。
2. 列出未满足项与遗留风险，逐条写明「需要谁决定什么」。
3. 给出结论：接受 / 回修（第 N 次）/ 升级。
4. 核验表落盘到 `reports/acceptance.md`。

## 约束

- 口径：`ots:R-6`（验收对象是已实现的代码与实跑结果，不只是文档）。
- 禁改：全部功能代码、契约文件、`tests/acceptance/**`。
- 契约：本单不涉及契约定义与产物。
- 迁移号：无。
- 基线：`feature/example-integration`。
- 越界处置：需要改范围外文件 / 改契约 / commit / push / 合并时，停下上报。
- 歧义处置：业务歧义停下上报；实现歧义自行决定并在回报中写明选择与理由。

## 归属

- 本单独占文件：
  - `reports/acceptance.md`
- 依赖：VER-001
- 与他单相邻：上游 `VER-001`；交付门由拍板人签字。
- 分支：`feature/ACC-001-accept`
- 补丁包路径：`patches/ACC-001/verifier/`
