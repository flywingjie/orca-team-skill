# 工单 INT-001：合并前后端并统一生成契约产物

## 目标

合入 `API-014` 与 `WEB-021` 两支补丁，统一生成契约产物，注册路由，并跑全量门禁。
本单是**契约产物的唯一写入方**，也是**共享文件**的唯一写入方。

**不碰**：
- `contracts/example.py`（契约定义归 `CTR-001` 单，不得改）
- `server/example.py`、`server/tests/`、`web/src/example.tsx`（功能代码归各实现单）

## 改动

1. 合入 `API-014` 与 `WEB-021` 的补丁，解决冲突；冲突涉及契约定义时**回退 `CTR-001` 单**。
2. 统一生成契约产物到 `contracts/generated/`。
3. 在 `server/routes.py` 注册路由（共享文件，本单独占）。
4. 跑全量门禁，输出结果到补丁包 `evidence/`。

## 约束

- 口径：`ots:P-1`（契约分两层）、`ots:P-4`（同一文件不并行）。
- 禁改：`contracts/example.py`、`server/example.py`、`server/tests/**`、`web/src/example.tsx`。
- 契约：**本单是契约产物的唯一写入方**；不得改契约定义。
- 迁移号：无。
- 基线：`feature/example-integration`。
- 越界处置：需要改范围外文件 / 改契约 / commit / push / 合并时，停下上报。
- 歧义处置：业务歧义停下上报；实现歧义自行决定并在回报中写明选择与理由。

  - `contracts/generated/`
